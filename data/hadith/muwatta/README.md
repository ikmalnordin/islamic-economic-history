# Muwatta Imam Malik — Structured Extraction Index

**Source:** `موطأ مالك_يحيى_1.pdf` (Riwayah Yahya al-Laythi, Vol. 1), as uploaded to this repository.
**Method:** This PDF has no extractable text/OCR layer, so every narration is transcribed by rendering each page as an image and reading it directly. Extraction proceeds book by book, in page-range batches, with progress committed incrementally.
**Schema:** Each book's table has four columns — narration number, Book/Chapter, Isnad (chain of narrators), and Matn (Arabic text).

Note: per this edition's own footnote (page 33), it merges what other editions split into ~15 separate books (purification, prayer times, Friday prayer, funerals, etc.) into a single "Kitab as-Salah" — so Book 1 is far larger than the rest.
